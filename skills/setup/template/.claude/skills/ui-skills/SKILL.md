# UI Skills

Fallback stub. Run `npx ui-skills start` for the full routing skill (UI Skills by ibelick, MIT).

1. Decide if the task is UI-related; if not, no skill is needed.
2. `npx ui-skills categories`, then `npx ui-skills list --category <category>`.
3. Load the smallest useful set with `npx ui-skills get <slug>`: prefer 1, use 2 for two clear angles, 3 only for broad work, never more.
4. Route by topic, then stack, then specificity; prefer framework-specific skills when the stack is obvious.
5. Implement following the loaded skills.
